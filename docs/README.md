# Multilingual Corporate Website & CMS

A modern, high-performance multilingual website and CMS built with Next.js 15, Payload CMS, and PostgreSQL.

## 🚀 Tech Stack

- **Frontend:** Next.js 15 (App Router), TypeScript, Tailwind CSS, Shadcn UI, Motion
- **Backend & CMS:** Payload CMS
- **Database:** PostgreSQL
- **Internationalization:** next-intl (fa, en, ar)
- **Infrastructure:** Docker, Docker Compose
